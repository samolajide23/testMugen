|Tyrone the Fox By DoomJoshuaBoy| 
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This character is formerly sprite based from Tails by Mugen Hunter for the OC.
The character names "Sonic, Tails and Amy Rose" and Voices are all by SEGA except for the OC.
The voice the OC uses is from Akuma/Gouki by Capcom.
The character uses sparks and projectiles from KOF XI.
This character is 4 button config. 
The Weapons, assets and sounds is from Original Doom and Quake by ID Software.

|Movelist|

 D - down        y - hard punch       	b - hard kick
 F - forward     z - power up       	c - knockdown
 B - back        p - any punch          k - any kick
 s - start       2p- two punches        2k- two kicks
